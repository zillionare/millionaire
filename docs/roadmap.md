# 版本状态与后续方向

本页只说明当前源码已经具备什么、哪些边界仍需补齐，不承诺发布日期。原生安装包与 GitHub Release 的版本可能滞后；下载时以 Release 文件名和校验值为准。

## 当前状态

当前源码树已经包含：

- 日线、月线与 30 分钟策略路径，以及回测、Paper 和独立 HTTP 模拟柜台。因子研究以日线为研究单位；
  30 分钟行情供策略执行与影子对照使用。
- 以 `epoch` 为边界的数据完整性检查、尾部优先/近期历史优先的回补编排，以及不可补全缺口的风险事件和回测预检。
- 因子研究、参数优化、SHAP 预测解释、账户事实收益归因。
- 源码级离线审计：未来扰动、随机/置换对照、人工 oracle、账户不变量和关键变异。
- 三平台原生安装、服务控制器、进程恢复与升级/卸载验收。

这些能力的具体边界见[本版能力与版本状态](scope.md)；v0.5 的 28 项验收（AC-5001～AC-5028）逐项绑定
具体测试节点，以 `python -m quantide.audit.acceptance --scope v05 --results <JUnit>` 的实际输出为准。
每条研究证据绑定当时的价格口径、依赖指纹和历史数据快照，旧证据不能复用到新构建。

## 后续方向

### 1. 30 分钟影子归因

日线与 30 分钟 Shadow-Run 均可按各自周期运行；30 分钟影子使用闭合 bar、跨 bar 恢复和缺口回补，并在对照页展示逐 bar 净值。后续继续完善订单级归因和更多异常场景证据。

### 2. 数据源能力矩阵与多源组合

继续完善历史、实时和参考数据的独立能力矩阵，包括凭证、权限、配额、空响应诊断、多源切换和 Tushare `rt_min`、历史分钟、指数实时等适配。当前自动接入的是 `rt_k` 股票快照；`rt_min` 等接口需要通过用户扩展或后续版本接入。

数据完整性回补目前按 `epoch` 从尾部向历史推进，每轮有本地窗口预算。真实额度驱动、跨源补齐和更细的告警合并仍可继续完善。

### 3. 审计证据与平台门禁

离线审计入口已经存在，但仍需继续补齐跨平台确定性证据、完整变异矩阵和更多数据源/柜台组合。发布结论只对绑定的源码、配置、数据和审计配置有效；旧报告不能复用到新构建。

### 4. 安装与运行证据

原生包尚未配置 Apple Developer ID/公证或 Windows 发行者代码签名。操作系统断电、重启和多个完整交易日无人值守仍需现场证据；托管 runner 不能替代真实桌面和券商环境。

## 不在规划中的内容

CE 不增加真实交易、券商柜台程序、三重障碍/回撤卖出/成本止损等私有风险程序，也不提供对任意 Python 策略的安全沙箱。需要这些能力时，应使用 millionaire pro 或由宿主显式装配适配器。
