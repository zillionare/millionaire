# 预测解释与收益归因

这里有两类不同证据：

- **SHAP 预测解释**回答“这些因子如何影响本次模型分数”；
- **账户事实收益归因**回答“这段时间的权益变化来自哪些资产、策略、交易和成本”。

前者不是收益归因，后者也不是对因子因果作用的证明。

## 打开单次决策解释

1. 完成 `MLMomentumReversalStrategy` 回测并打开报告。
2. 进入“交易详情”，点击成交对的 K 线入口。
3. 在交易面板查看“买入归因”或“卖出归因”，以及“特征 / 特征值 / 归因权重”。
4. 对照证券、决策日、训练/选池日期和该次使用的配置，理解输入与分数。

是否显示解释由策略能力决定：策略声明 `ATTRIBUTION = "shap"` 并实现预测解释接口。普通双均线没有这一模型能力；不能因其没有 SHAP 面板就认定策略运行失败。数据不足、证券不在截面或无法重建上下文时可能没有解释，不能把缺失当成零贡献。

## 怎样读 SHAP

正贡献表示相对该模型基准把分数向上推，负贡献相反；它不是该因子赚了多少元。当前示例将预测分数和贡献按截面尺度处理，应在同一模型/截面口径下比较。因子相关时，贡献分配会受特征组合和模型影响，不能把贡献大小直接当作独立因果效应。

例如某因子推高买入分数，随后股票下跌，二者并不矛盾：解释的是当时的预测，实际收益还受到选股、权重、执行时点、成交价格、费用和后续市场变化影响。卖出也可能来自不再入选 `top_k`，不能将所有退出都理解为一个负向 SHAP 阈值。

## 账户收益归因

仿真账户页面提供“收益归因”入口，路径形如 `/attribution/<账户ID>`；同一页面的纯文本版本位于 `/attribution/<账户ID>/markdown`。报告从账户事实快照读取权益、持仓、成交、费用、外部现金流和公司行为，给出：

- 期初/期末权益、成本和显式残差；
- 按资产的贡献和按策略的贡献；
- 同区间基准的总收益与超额收益（提供基准时）；
- 数据不足或口径缺失时的明确警告。

归因保留 `unassigned` 残差，不把无法证明来源的权益变化强行分摊。账户事实不足时报告返回 `INSUFFICIENT`，不会补造快照或假装完成拆分。

## 保留可复现上下文

保留当时的策略和因子源码、训练配置、因子集、证券池、数据与模型版本。历史解释需要重建相应训练/选股过程；源码或数据发生变化后，重新计算的解释不能直接当作旧运行的不可变审计记录。收益归因同样受账户事实、估值价格和公司行为数据完整性影响，应同时保存报告指纹和缺失警告。

SHAP 与收益归因并列展示，不能用“归因”一名混用两者。完整命令、边界和审计证据见[策略与因子审计](strategy-audit.md)。
