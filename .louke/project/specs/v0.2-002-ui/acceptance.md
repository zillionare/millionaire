## §2.1 系统壳层与认证

<a id="ac-fr-0110"></a>
## FR-0110 启动路由分流

### AC-1
- (Round 11 - 选 redirect 单一路径, 与 FR-0460 AC-1 一致) 全新安装后访问 `/` 或任何非 wizard 路径 → 自动跳转到 init-wizard 第一步 (欢迎页)
- 此时尝试访问 `/dashboard` → 重定向到 wizard 欢迎页 (即 `/` 路径, 而**不**是 403)
### AC-2
- 已完成 init-wizard 的系统, 未登录访问 `/` → 重定向到 `/login`; 登录成功后跳转回 `/`

<a id="ac-fr-0120"></a>
## FR-0120 单用户登录与会话

### AC-1
- 登录页输入正确用户名+密码 → 跳转到 `/dashboard` 并建立会话; 后续访问受保护页面不再要求登录
### AC-2
- 输入错误密码 5 次 → 仍可继续尝试 (不锁定账号); 连续错误不被记录到任何用户可见的登录历史

<a id="ac-fr-0130"></a>
## FR-0130 登出与个人设置

### AC-1
- 用户菜单点击"退出登录" → 会话被清除, 跳转回 `/login`; 再次访问受保护页面要求重新登录
### AC-2
- 用户菜单点击"修改密码" → 进入密码修改页, 需输入旧密码 + 两次新密码
### AC-3
- 旧密码错误 → 提交失败, 表单显示"旧密码错误"; 旧密码正确但两次新密码不一致 → 表单显示"两次输入不一致"; 提交成功后用旧密码登录失败, 用新密码登录成功
### AC-4
- 验证 UI **无** "改昵称" 入口 (story §1.2 Aaron "不做")

<a id="ac-fr-0140"></a>
## FR-0140 未登录访问重定向

### AC-1
- 未登录访问 `/dashboard/accounts/123` → 重定向到 `/login?next=/dashboard/accounts/123`
### AC-2
- 登录成功后 → 自动跳转到 `/dashboard/accounts/123` (deep link 保留); 浏览器返回按钮不破坏该行为

<a id="ac-fr-0150"></a>
## FR-0150 主界面布局

### AC-1
- 登录后页面顶部 nav bar 包含 brand (左) + 导航菜单 (中) + 告警图标与未读数 + 用户菜单 (右); 左侧为多级侧边导航, 右侧为主内容区
### AC-2
- 侧边栏折叠按钮 → 侧边栏收起, 主内容区扩展; 刷新页面后折叠状态被保留 (从 localStorage 读取)

<a id="ac-fr-0160"></a>
## FR-0160 告警中心入口与列表

### AC-1
- 系统产生 3 条未读告警 (例如数据同步失败) → 顶部告警图标右上角显示红色小圆点 + 数字 "3"
### AC-2
- 点击告警图标 → 进入告警中心列表, 列表按时间倒序, 每条展示时间 / 来源 / 级别 / 摘要
### AC-3
- 点击单条告警"标记已读" → 该条样式变化 (灰色) + 顶部未读数减 1
### AC-4
- 勾选多条点击"批量确认" → 选中条目状态变为"已确认", 顶部未读数相应减少
### AC-5
- 未读数刷新走**推送机制** (非定时轮询); 具体协议 (SSE / WebSocket) 由实施阶段决定; 验证: 关闭后端事件源 (例如停止推送服务), 未读数应在合理时间内反映变化 (而非依赖定时轮询)
### AC-6
- 推送断线时, 告警图标显示"重连中"状态; 重新建立连接后, 未读数自动同步

<a id="ac-fr-0170"></a>
## FR-0170 UI 内通知 (toast / banner)

### AC-1
- 提交订单成功 → 页面顶部居中弹出绿色 toast "已发送, 订单号 xxx" + ✓ 图标, 3 秒后自动消失 (鼠标 hover 时暂停)
### AC-2
- 触发订单失败 → 弹出红色 toast "失败原因: ..." + ✕ 图标, **不自动消失**, 必须手动点击关闭
### AC-3
- 跳过 wizard 某步骤 → 页面顶部紧贴 header 下方出现黄色 banner "已跳过 [步骤名], 可稍后处理" + ⚠ 图标, 持续到用户主动关闭
### AC-4
- 多个 toast 同时触发 → 纵向堆叠显示, 不重叠; 每个独立计时
### AC-5
- 错误 toast 含 ARIA `role="alert"` 属性, 可被屏幕阅读器读取

<a id="ac-fr-0180"></a>
## FR-0180 功能降级

### A 类降级 (永久, 无网关)

### AC-1
- A 类降级触发后, header 中 "交易" 菜单项置灰 (cursor: not-allowed); hover 显示 tooltip: "此功能因交易网关未配置而无法使用"
### AC-2
- A 类降级时, 直接 URL 访问 (例: `/trade/live`) 被后台拦截, 返回 503 + 提示页
### AC-3
- A 类降级时, "启动仿真" 入口 disabled; 点击不触发任何操作
### AC-4
- A 类降级时, "转入实盘" 入口 disabled
### AC-5
- A 类降级时, "启动回测" 入口 **仍可用** (回测不依赖 gateway, 可用历史数据回放)
### AC-6
- A 类降级时, "实盘补单"/"实盘撤单" 等所有依赖 gateway 的入口 disabled
### AC-7
- A 类降级时, 网关管理 (§2.6 FR-0340) 入口 **仍可用** (用来配置 gateway)

### AC-8
- 用户在 A 类降级时配置 gateway (填 server/port/url_prefix/api_key) -> 立即解除降级, 所有被禁止入口立即恢复

### B 类降级 (临时, 网关偶发不可连)

### AC-9
- B 类降级触发后, 顶部出现黄色 banner, banner 内含红色 ⚠ 图标 + 红色文字 "交易网关连接断开, 数据可能不刷新" + "告警中心" 链接 + 关闭按钮 (非大面积红色背景, Round 10c 统一: 黄底 + 红色文字/图标)

### AC-10
- B 类降级时, 主内容区页面布局不变, 已有数据继续展示 (不空白)

### AC-11
- B 类降级时, 数据不要求实时刷新 (stale 可接受)
### AC-12
- B 类降级恢复后, banner 自动消失

### A 类与 B 类转换规则

### AC-13
- A 类配置 gateway 提交后**立即**变正常 (不需要测试通过)
### AC-14
- A 类降级期间提交无效 gateway -> 进入 B 类 (临时) 降级
### AC-15
- B 类降级**永不升级为 A 类** (B 类临时降级不会变永久)
### AC-16
- B 类降级期间运行中的实盘策略行为 (订单暂存 / 自动 dry-run 等) **不属于 UI 职责**, 由后台异常处理流程决定 (BACKEND-REVIEW-001 跟踪)

### 降级状态 UI 表现

### AC-17
- A 类降级时, 顶栏"交易"菜单按钮: 灰色, cursor: not-allowed
### AC-18
- A 类降级时, 顶栏"交易"菜单 hover 显示 tooltip: "此功能因交易网关未配置而无法使用"
### AC-19
- A 类降级时, "启动回测" 按钮仍可点击, 且**不需要**提示"交易网关未配置"
### AC-20
- B 类降级时, 顶栏正下方出现黄色 banner (背景黄色, 非红色背景; banner 内文字+图标用红色, 满足 §3 NFR-0040 "禁止大面积红色背景" 约束, Round 10c 统一)
### AC-21
- B 类降级时, banner 右侧"告警中心"链接跳转 §2.1 FR-0160
### AC-22
- B 类降级时, banner 用户可关闭, 但下次断连时仍重新出现
### AC-23
- B 类降级时, 主内容区不空白, 已有数据继续展示

<a id="ac-fr-0020"></a>
## FR-0020 运行时参数编辑

### AC-1
- 启动回测表单包含字段: 本金 / 滑点 / 印花税比率 / 佣金比率 / 单笔最低佣金; 默认值按 spec 表格填充 (本金取上一次值, 滑点 0, 印花税 0.001, 佣金 0.0001, 单笔最低佣金 5)
### AC-2
- 本金输入 `-100` → 提交被阻止, 显示 "本金必须 > 0"; 滑点输入 `0.2` → 提交被阻止, 显示 "滑点必须在 0~0.1"
### AC-3
- 完成一次回测后, 启动仿真时表单显示"沿用上次 / 重新设置"两选项; 默认选中"沿用上次", 数值与上次一致
### AC-4
- 修改运行时参数后启动回测 → 回测结果中"参数快照"显示本次参数; 后续启动仿真默认值与本次不同 (验证"不写入回测结果")

<a id="ac-fr-0040"></a>
## FR-0040 调度操作界面

### AC-1
- 策略选择器选中某日线策略 → "启动回测"按钮可见; 选中后弹出表单含 策略参数 (可编辑) + 运行时参数 + 回测区间 (起止日期)
### AC-2
- 已完成回测结果显示"转仿真"和"转实盘"两个按钮; 实时策略的回测结果不显示这两个按钮 (实时策略走 001-FR-240 直接进入仿真/实盘)
### AC-3
- 仿真中策略显示"停止"按钮; 实盘中策略显示"停止"和"进入 dry-run"两个按钮
### AC-4
- 点击"停止" → 策略状态变为"已停止", 已发出的订单继续在 001-FR-210 账本中执行 (验证"已发订单不撤回")
### AC-5 (Round 15 - 转入表单字段)
- 转入仿真 / 转实盘表单接受运行时参数 (本金/滑点/印花税/佣金/最低佣金) + 运行时模式 (paper/live) + 账户名 (字符串, 不允许空) + 本金 (数字 > 0)
- 转入回测表单只接受运行时参数, 不接受账户名/本金 (回测不创建账户)
### AC-6 (Round 15 - 本金创建后只读)
- 创建账户后, §2.4 FR-0410 账户详情页本金字段**只读**, **不**允许修改 (无编辑按钮/无保存按钮)
- §2.2 FR-0201 概览 / §2.3 FR-0040 转入表单均**不**接受本金修改入口
### AC-7 (Round 15 - 实盘总账户本金可改)
- §2.5 FR-0420 实盘交易界面 (无策略选中时, 顶部"实盘总账户"信息卡片右侧 "编辑本金" 按钮) **可编辑**本金字段; 保存时校验 > 0
- 用户追加本金: 输入新本金数字 → 保存 → 账户实际资金增加
- 用户抽走本金: 输入新本金数字 (小于原本金) → 保存 → 账户实际资金减少; 后台约束不允许抽至负数, 输入小于"已用资金"的本金时校验失败, 不保存
- §2.6 FR-0340 网关管理页: 顶部"实盘总账户"行**也**显示 "编辑本金" 按钮 (与 FR-0420 等效, 两个入口都生效)

<a id="ac-fr-0060"></a>
## FR-0060 dry-run 切换与并行仿真视图

### AC-1
- 实盘策略菜单点击"进入 dry-run" → 弹出二次确认对话框, 提示"已发订单仍会成交"; 确认后策略状态徽章变为 `dry-run`
### AC-2
- 策略详情页"并行仿真视图"显示**单 Y 轴双线图**: 一条线为实盘/dry-run 期间真实净值, 另一条线为并行仿真模拟净值
### AC-3
- dry-run 期间点击"退出 dry-run" → 二次确认; 确认后策略状态徽章恢复为 `live`
### AC-4
- (Aaron Round 10c 澄清: 运行时实例控制语义) "停止" 操作 (FR-0040 AC-4): 终止策略, **不可重启**, 策略需以全新实例再次运行 (story §3.3 Aaron 注)
- "暂停" 操作 (实盘 dry-run, 本 FR-0060): 策略继续运行但不再发出新订单, 已发订单仍会成交, 可通过"退出 dry-run"恢复为 `live`
- "重启" 语义: 仅指暂停 (dry-run) 后恢复, **不**适用于"已停止"的实例 (停止后只能新建实例)

<a id="ac-fr-0070"></a>
## FR-0070 风控触发事件详情

### AC-1

## FR-0411 账户管理 - 隐藏与显示

> **Sage Round 10b (Codex P1-2)**: 区分两层隐藏语义。`account.hidden` 服务端字段决定是否真隐藏; `display_hidden_accounts` localStorage 仅决定是否在 UI 显示已隐藏账户。

### AC-1
- 账户管理页面 -> 列出所有账户 (运行中 + 已终止); 当 `display_hidden_accounts` localStorage = false (默认) 时, `account.hidden = true` 的账户不出现在列表中

- 选中处于"空闲 + 无未结算持仓"状态的账户 -> "隐藏"按钮可点击 -> 二次确认 (输入账户名) -> 提交成功后服务端写入 `account.hidden = true`, 该账户从 FR-0390 列表和 FR-0201 概览 中消失

### AC-3
- 选中非空闲 (有运行中策略绑定) 或有未结算持仓 (持仓 ≠ 0) 的账户 -> "隐藏"按钮置灰 + tooltip 提示原因 ("账户非空闲" 或 "存在未结算持仓"); 用户无法触发隐藏

- 隐藏成功后, FR-0201 概览 合计行 (总资产 / 可用现金 / 持仓市值 / 账户盈亏) 与 FR-0390 表格合计行均**不**包含被隐藏账户的数值 (story §4.3.2/§4.3.4 "被隐藏的账户不参与各类合计统计")

### AC-5
- "显示已隐藏账户"开关从关闭切到开启 -> `display_hidden_accounts` localStorage 写入 true, 已隐藏账户 (`account.hidden = true`) 以灰色样式出现在列表中; 开关切回关闭 -> 已隐藏账户再次消失

### AC-6
- 在"显示已隐藏账户"开关开启状态下, 选中灰色隐藏账户 -> "取消隐藏"按钮 -> 服务端写入 `account.hidden = false` -> 该账户恢复正常样式并重新参与 FR-0201/FR-0390 合计统计

### AC-7
- `display_hidden_accounts` 开关状态通过 localStorage 持久化, 刷新页面后保持; 清空 localStorage 后, 开关回到默认 (关闭), 但 `account.hidden = true` 的账户仍然保持隐藏状态 (换浏览器/清 localStorage 后隐藏仍然生效, 因隐藏事实由服务端字段决定)

### AC-8
- 验证 UI **无**"创建账户"/"删除账户"/"重置账户"入口 (Aaron 限制范围; 仿真账户由策略调度运行时创建, 实盘虚拟账户由投入实盘时创建)

## §2.8 系统配置 (init-wizard)

<a id="ac-fr-0460"></a>
## FR-0460 系统配置 init-wizard

### AC-1
- 全新安装后访问 `/` → 自动跳转到 wizard 欢迎页; 此时尝试访问 `/dashboard` → 重定向到 wizard 欢迎页 (即 `/` 路径) (Round 10c: 选定"重定向"为单一主路径, 不用 403)
### AC-2
- 按引导依次完成:
  1. 欢迎
  2. 运行环境 (监听地址/端口/URL 前缀/是否仅本机)
  3. 管理员账号 (用户名 + 密码)
  4. 数据目录
  5. Tushare 数据源
  6. 交易网关 (可选项)
  7. 首次下载范围 (交易日历起止、历史行情数据时长, 默认最近 1 年)
  8. 下载进度 (必选父步骤, 实时显示每个子任务的进度, 父步骤不能跳过; 子任务失败时可延后)
  9. 通知配置 (可选项)
  10. 完成页
  - **可选项步骤** (交易网关 / 通知配置) 允许用户主动**跳过**, 即使未配置也可进入下一步
  - **必选项步骤** (欢迎 / 运行环境 / 管理员账号 / 数据目录 / Tushare 数据源 / 首次下载范围 / 下载进度) 不允许跳过, 必须填写并通过校验后才能进入下一步 (Round 15 加"下载进度"到必选)
  - **下载进度是必选父步骤** (Round 15): 其子任务 (例: 某个股票历史行情下载) 失败时可延后, 标"待处理", 主界面 banner 同步显示; 延后**不**阻断父步骤的完成
### AC-3
- 步骤下载失败:
    - **必选项父步骤失败** (例: 步骤 1 欢迎, 步骤 3 管理员账号): 界面仅显示"重试"按钮 (无"跳过"), 用户停留在此步直到成功或放弃重试; 已成功步骤不被回退
    - **必选项父步骤"下载进度"的子任务失败** (例: 某个股票历史行情下载失败, Round 15): 界面显示"重试该子任务" + "跳过该子任务 (延后)" 按钮; 跳过 → 该子任务标"待处理", 父步骤不阻断, 主界面 banner 同步显示
    - **可选项步骤失败**: 界面显示"重试" + "跳过" 按钮; 点击"跳过" → 该步骤标记为"待处理" (后续可在系统设置 §2.1 中补做); 跳过则该步不再提示需立刻处理
    - 配置完成判定: 全部必选项步骤 + 全部可选项步骤 (状态为"已完成"或"待处理") → 进入完成页
### AC-4
- init-wizard 流程入口在**首次启动时自动出现** (系统检测到未初始化状态即触发); 用户不需要从菜单/命令行手动调用; wizard 未走完前, 其他任何页面都打不开 (§1.1 启动路由分流 §2.1 FR-0110 保证)
### AC-5
- 重新进入 wizard (从系统设置) → 步骤顺序同首次; **不允许**修改管理员密码字段; **不允许**修改数据目录字段; 完成后不重启进程直接回主界面
### AC-6 (Round 15 加关闭按钮)
- 主界面顶部出现黄色横幅: "还有 N 个待处理的 wizard 步骤" + "去补做"链接 + 关闭按钮 ✕ (验证被跳过的可选项提示)
- 用户点击关闭按钮 ✕ → 横幅**立即消失**, 再次访问任何页面不显示该横幅 (除非重新进入 wizard 又有新跳过/失败)
- 关闭横幅后, 用户随时可在 §2.1 FR-A130 系统设置 → 重新配置 wizard 中补做被跳过的可选项
### AC-7
- init-wizard 完成后, 启动路由分流 (§2.1 FR-0110) 生效: `/` 跳转到 `/login`, 不再进入 wizard
