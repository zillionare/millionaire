## §2.1 系统壳层与认证

### UI-FR-A110 启动路由分流

- AC-1: 全新安装后访问 `/` 或任何非 wizard 路径 → 自动跳转到 init-wizard 第一步 (欢迎页), 此时访问 `/dashboard` 返回 403 或重定向到 wizard
- AC-2: 已完成 init-wizard 的系统, 未登录访问 `/` → 重定向到 `/login`; 登录成功后跳转回 `/`

### UI-FR-A120 单用户登录与会话

- AC-1: 登录页输入正确用户名+密码 → 跳转到 `/dashboard` 并建立会话; 后续访问受保护页面不再要求登录
- AC-2: 输入错误密码 5 次 → 仍可继续尝试 (不锁定账号); 连续错误不被记录到任何用户可见的登录历史
- AC-3: 登录成功后保持会话 24 小时不操作也不自动登出 (验证"不做超时自动登出"约束)

### UI-FR-A130 登出与个人设置

- AC-1: 用户菜单点击"退出登录" → 会话被清除, 跳转回 `/login`; 再次访问受保护页面要求重新登录
- AC-2: 个人设置页修改昵称 → 提交后右上角用户菜单立即显示新昵称, 数据库 `users` 表对应记录的 `nickname` 字段已更新
- AC-3: 修改密码时, 旧密码错误 → 提交失败, 表单显示"旧密码错误"且新密码不被接受; 旧密码正确且新密码通过强度校验 → 提交成功后用旧密码登录失败, 用新密码登录成功

### UI-FR-A140 未登录访问重定向

- AC-1: 未登录访问 `/dashboard/accounts/123` → 重定向到 `/login?next=/dashboard/accounts/123`
- AC-2: 登录成功后 → 自动跳转到 `/dashboard/accounts/123` (deep link 保留); 浏览器返回按钮不破坏该行为

### UI-FR-A150 主界面布局

- AC-1: 登录后页面顶部 nav bar 包含 brand (左) + 导航菜单 (中) + 告警图标与未读数 + 用户菜单 (右); 左侧为多级侧边导航, 右侧为主内容区
- AC-2: 侧边栏折叠按钮 → 侧边栏收起, 主内容区扩展; 刷新页面后折叠状态被保留 (从 localStorage 读取)

### UI-FR-A160 告警中心入口与列表

- AC-1: 系统产生 3 条未读告警 (例如数据同步失败) → 顶部告警图标右上角显示红色小圆点 + 数字 "3"
- AC-2: 点击告警图标 → 进入告警中心列表, 列表按时间倒序, 每条展示时间 / 来源 / 级别 / 摘要
- AC-3: 点击单条告警"标记已读" → 该条样式变化 (灰色) + 顶部未读数减 1
- AC-4: 勾选多条点击"批量确认" → 选中条目状态变为"已确认", 顶部未读数相应减少

## §2.2 Dashboard (概览)

### UI-FR-D201 账户总览 (Dashboard)

- AC-1: 登录后 `/dashboard` 页面顶部"账户总览"区块显示 1 个实盘账户 (总资产/可用/持仓/当日盈亏/累计盈亏) + N 个虚拟账户列表 (按总资产降序)
- AC-2: 点击虚拟账户行 → 跳转到该账户详情页 (§2.4 UI-FR-410); 点击实盘账户区块 → 进入实盘交易界面 (§2.5 UI-FR-420)

### UI-FR-D202 计划任务

- AC-1: Dashboard 中部"计划任务"区块列出今日 (按时间顺序) 即将触发的策略任务, 每条显示策略名 / 触发时间 / 类型
- AC-2: 切换"未来 7 天 / 未来 30 天"按钮 → 列表内容切换
- AC-3: 同时显示数据同步任务 (来自 §2.6 UI-FR-0310), 每条显示任务名 / 下次运行时间 / 上次状态
- AC-4: 点击策略任务 → 跳转到该策略的仿真/实盘详情页; 点击数据任务 → 跳转到系统管理任务调度页

### UI-FR-D203 告警分类显示

- AC-1: Dashboard 底部"告警"区块按"策略类 / 系统类"两组, 每组最多展示 5 条最新告警
- AC-2: 每条告警按级别显示颜色: 错误 (红) / 警告 (黄) / 提示 (蓝)
- AC-3: 点击"策略类"分组标题 → 跳转到告警中心 (§2.1 UI-FR-A160) 并自动应用"策略类"过滤
- AC-4: 单条告警点击"标记已读" → 该条样式变化, 顶部未读数同步减少

## §2.3 策略

### UI-FR-010 策略发现与展示

- AC-1: 策略选择器列出所有 `is_builtin=False` (用户策略) 和 `is_builtin=True` (内置策略); 默认 `is_builtin=False` 优先 + `name` 字母升序
- AC-2: 用户策略与内置策略 `strategy_id` 冲突时, 列表只显示用户版本; 开启"显示被覆盖的内置策略"开关 → 内置版本出现并标注"被覆盖"
- AC-3: 搜索框输入 "ma" → 列表过滤为 `name` / `description` / `strategy_id` 含 "ma" 的策略
- AC-4: 按 `strategy_type` 多选过滤 (例如勾选 `day` + `live`) → 列表仅显示该类型策略

### UI-FR-020 运行时参数编辑

- AC-1: 启动回测表单包含字段: 本金 / 滑点 / 印花税比率 / 佣金比率 / 单笔最低佣金; 默认值按 spec 表格填充 (本金取上一次值, 滑点 0, 印花税 0.001, 佣金 0.0003, 单笔最低佣金 5)
- AC-2: 本金输入 `-100` → 提交被阻止, 显示 "本金必须 > 0"; 滑点输入 `0.2` → 提交被阻止, 显示 "滑点必须在 0~0.1"
- AC-3: 完成一次回测后, 启动仿真时表单显示"沿用上次 / 重新设置"两选项; 默认选中"沿用上次", 数值与上次一致
- AC-4: 修改运行时参数后启动回测 → 回测结果中"参数快照"显示本次参数; 后续启动仿真默认值与本次不同 (验证"不写入回测结果")

### UI-FR-040 调度操作界面

- AC-1: 策略选择器选中某日线策略 → "启动回测"按钮可见; 选中后弹出表单含 策略参数 (可编辑) + 运行时参数 + 回测区间 (起止日期)
- AC-2: 已完成回测结果显示"转仿真"和"转实盘"两个按钮; 实时策略的回测结果不显示这两个按钮 (实时策略走 001-FR-240 直接进入仿真/实盘)
- AC-3: 仿真中策略显示"停止"按钮; 实盘中策略显示"停止"和"进入 dry-run"两个按钮
- AC-4: 点击"停止" → 策略状态变为"已停止", 已发出的订单继续在 001-FR-210 账本中执行 (验证"已发订单不撤回")

### UI-FR-060 dry-run 切换与并行仿真视图

- AC-1: 实盘策略菜单点击"进入 dry-run" → 弹出二次确认对话框, 提示"已发订单仍会成交"; 确认后策略状态徽章变为 `dry-run`
- AC-2: 策略详情页"并行仿真视图"显示**双 Y 轴净值曲线**: 主轴实盘/dry-run 期间真实净值, 副轴并行仿真模拟净值
- AC-3: dry-run 期间点击"退出 dry-run" → 二次确认; 确认后策略状态徽章恢复为 `live`

### UI-FR-070 风控触发事件详情

- AC-1: 风控策略触发卖出后, "风控触发事件"页面列表展示每条事件的: 时间戳 / 标的 / 触发价 / 成本价 / 原因 / 超额收益
- AC-2: 超额收益列默认 N=0 (当日收盘); N 日窗口未关闭时显示"计算中..."占位
- AC-3: "触发原因分布"饼图按 `reason` 字段分组; 点击某原因切片 → 触发事件列表过滤为该原因的事件

### UI-FR-080 回测进度可视化

- AC-1: 启动回测后, 进度条 x 轴为回测区间, 当前推进点高亮, 百分比 = 已处理交易日 / 总交易日
- AC-2: 净值曲线组件随 `on_bar` 推进逐点增加, 主轴策略净值, 副轴沪深 300 基准
- AC-3: 实时指标区显示: 当前持仓 / 当日盈亏 / 累计交易笔数; 不显示年化/最大回撤/Sharpe/Sortino/Calma, 这些位置显示占位符"回测结束后计算"
- AC-4: K 线图上买入点叠加 ▲, 卖出点叠加 ▼; hover 显示价格 / 数量 / 时间
- AC-5: 回测结束后, "概览"页签显示参数快照 (只读) + 评估指标 + 净值曲线 + 交易信号 + 回撤图 + 月度热力图
- AC-6: "每日成交"页签显示所有成交记录按时间排序, "导出 CSV" 按钮 → 下载文件第一行为表头
- AC-7: "日志"页签显示 stdout/stderr, "下载到本地" 按钮 → 文件下载成功; 单条日志可点击"删除"

### UI-FR-260 调度 UI

- AC-1: 验证 §2.3 中 UI-FR-010/020/040 三条 AC 全部通过 (本 FR 是聚合入口, AC 由子 FR 覆盖)

### UI-FR-370 核心图表

- AC-1: 回测报告"概览"页签加载时, 净值曲线 / 回撤图 / 月度收益热力图 三个组件均渲染成功 (DOM 中包含 svg 或 canvas)
- AC-2: 月度收益热力图: x 轴年份, y 轴月份; 单元格颜色深浅对应收益高低; hover 显示具体数值

### UI-FR-380 回测进度

- AC-1: 验证 §2.3 中 UI-FR-080 的 AC-1~AC-4 全部通过 (本 FR 与 UI-FR-080 等价)

## §2.5 交易

### UI-FR-420 实盘交易界面

- AC-1: 顶部策略选择器列出所有实盘运行策略 (日线 + 实时); 未选择策略时显示总账户基本信息, 此时"买入"按钮置灰
- AC-2: 选中某策略 → 显示该策略的账户基本信息 + 当日委托列表 + 当日成交列表 (实时刷新, 延迟 < 5s)
- AC-3: 下单表单参考价可选 昨收 / 5 日均线 / 实时价; 选中昨收时下方显示"±1% / ±2% / ±3%" 涨跌速算价按钮
- AC-4: 卖出时"可卖数量"自动 = 持仓 − 已挂单; 表单下方红色提示"T+1: 今日买入的股票明天才能卖出"
- AC-5: 持仓列表双击某行 → 下单表单自动填充 标的 / 数量 / 价格
- AC-6: 金额输入框输入 `10000` + 标的价 `12.34` → 自动反算股数 = floor(10000 / 12.34 / 100) * 100
- AC-7: 点击"提交" → 成功后 toast "已发送, 订单号 xxx" + 订单出现在当日委托列表顶部
- AC-8: 故意触发下单失败 (例如余额不足) → toast 红色提示 + 失败原因; 表单数值不变, 可修改后再次提交
- AC-9: 断开 qmt-gateway 后下单 → toast "网关离线, 订单已暂存"; 订单进入本地队列
- AC-10: 在当日委托列表点击"撤单" → 委托状态变为"已撤"; 列表实时刷新 (延迟 < 5s)
- AC-11: 尝试把手动交易的目标策略选为风控策略 → 表单禁止提交, 显示"风控策略不可作为手动交易目标"

### UI-FR-430 仿真交易界面

- AC-1: 顶部策略选择器列出所有仿真运行策略; 选中后显示该策略账户基本信息 + 当日委托 + 当日成交
- AC-2: 交易界面无"下单辅助"区块 (无参考价切换、无可卖数量计算、无双击持仓带入)
- AC-3: 提供"补单"入口 (防止自动化失败), 补单流程与实盘下单表单一致但不校验风控目标

### UI-FR-400 委托和成交记录

- AC-1: tab 切换 "回测 / paper / live" → 委托列表内容切换
- AC-2: 委托记录按"策略 / 个股 / 时间段"组合筛选; 三者均可留空表示不限定
- AC-3: 成交记录列表展示: 策略 / 个股 / 时间段 / 成交价 / 成交量 / 成交时间; 同上可组合筛选

## §2.6 系统管理

### UI-FR-0310 数据同步任务的错误展示

- AC-1: `/system/tasks` 列出所有数据同步任务 (日线行情 / 证券列表 / 交易日历 / ST / 涨跌停); 每行展示 任务名 / 上次运行时间 / 状态
- AC-2: 失败任务显示"立即重试"按钮 → 点击后任务被触发, 状态变更为"运行中"
- AC-3: 任务右侧"启用/禁用"开关切换 → 任务调度列表中该任务状态同步切换
- AC-4: "立即手动跑一次"按钮 → 触发一次任务, 完成后状态更新
- AC-5: 修改 cron 表达式 (例如 `0 18 * * 1-5` → `0 19 * * 1-5`) → 保存后, 调度器下次按新 cron 触发
- AC-6: "查看历史"显示最近 N=10 次执行结果 (成功 / 失败 / 耗时 / 错误详情)

### UI-FR-0320 数据完整性校验报告展示

- AC-1: `/system/integrity` 页面展示校验报告:
  - 缺日列表: 交易日历缺失的日期 (例如 2024-01-15)
  - 重复日列表: 数据中重复出现的日期
  - 字段空值率: 各字段空值百分比, 超过阈值 (例如 5%) 标红
  - 校验历史: 最近 N=10 次校验结果 (时间 / 通过 / 失败原因)

### UI-FR-0330 个股查询与 K 线图

- AC-1: 搜索框输入"平安" → 列表显示名称含"平安"的个股 (按相关性排序)
- AC-2: 输入数字 "000001" → 列表显示代码为 000001 的个股
- AC-3: 输入拼音 "pingan" → 列表显示名称拼音为 "pingan" 的个股 (例如平安银行)
- AC-4: 选中某只个股 → 右侧展示 K 线图 (日线) + 关键字段 (开/高/低/收/量) hover tooltip

## §2.8 系统配置 (init-wizard)

### UI-FR-460 系统配置 init-wizard

- AC-1: 全新安装后访问 `/` → 自动跳转到 wizard 欢迎页; 此时 `/dashboard` 等页面无法访问
- AC-2: 按引导依次完成: 欢迎 → 运行环境 (监听地址/端口/URL 前缀/是否仅本机) → 管理员账号 (用户名+密码) → 数据目录 → 数据源 (一个或多个网关) → 首次下载范围 (交易日历起止/股票列表) → 下载进度 → 通知 (可跳过) → 完成页
- AC-3: 某步下载失败 → 用户停留在该步, 显示错误详情 + "重试" / "跳过" 按钮; 跳过则该步骤标记为"待处理"; 已成功的步骤不被回退
- AC-4: 主界面顶部出现横幅: "还有 N 个待处理的 wizard 步骤"
- AC-5: 重新进入 wizard (从系统设置) → 步骤顺序同首次; **不允许**修改管理员密码字段; **不允许**修改数据目录字段; 完成后不重启进程直接回主界面
- AC-6: init-wizard 完成后, 启动路由分流 (§2.1 UI-FR-A110) 生效: `/` 跳转到 `/login`, 不再进入 wizard
