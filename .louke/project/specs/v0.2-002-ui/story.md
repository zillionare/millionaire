# Millionaire UI — Story

本文件汇总所有面向用户、需要在 Web 界面中呈现或由用户操作触发的故事。**计算规则、调度规则、数据契约、撮合规则等业务规则不在本文件范围内**，仍由 [v0.2-001-strategy-framework](../v0.2-001-strategy-framework/story.md) 承载；本文件通过引用 001 的对应章节联动上游。

> **来源说明**：本文件的多数章节最初散落在 `v0.2-001-strategy-framework/story.md` 中，由 2026-06-17 的迁移整理集中到本文件。具体迁移记录见文件末尾"迁移记录"。

## 1. 系统壳层与认证

### 1.1. 第一次打开系统

用户在浏览器里打开 Millionaire 时，系统会判断自己是"刚装好"还是"已经配过了"。

- **刚装好**：用户被直接带入 init-wizard（§8），按引导设置管理员账号、运行环境、数据源等。Wizard 没走完之前，其它任何页面都打不开。
- **已经配过**：用户进入登录页，登录成功才进主界面。

### 1.2. 登录与个人设置

用户在登录页输入密码（用户名默认为 admin）。登录成功后进入主界面。

> Aaron: 这一版不做临时锁定和超时自动登出。

用户可以：

- 在右上角用户菜单里点"退出登录"回到登录页
- 在右上角用户菜单里点"修改密码"（要提供旧密码）

> Aaron: 不做查看最近的登录记录。

任何需要登录才能看的页面被未登录用户访问时，会被自动重定向到登录页；登录成功后跳回用户原本想去的地方。

### 1.3. 主界面长什么样

登录后用户看到的主界面由三部分组成：

- **顶部**：左边是系统 Logo 和名称；中间是导航菜单；右边是告警中心入口（带未读数小红点）、用户菜单。
- **顶部导航菜单**有概览，策略，数据管理，系统管理，交易等入口。
- **左侧导航栏**：是顶部导航菜单的二级菜单。左侧导航栏也允许多级菜单。用户可以折叠或展开侧边栏，状态会被记住。
- **主内容区**：当前所选页面的内容。

### 1.4. 告警中心

系统运行过程中产生的所有需要用户关注的事情（数据同步错误、网关断连、风控事件等）都汇总到"告警中心"。用户从header 中的 alert icon进入，看到按时间排列的告警列表。

每条告警有来源、级别、摘要；用户可以标记已读、批量确认，或者点进去跳到告警来源的详情页。

## 2. 概览

提供关键信息的一站式访问。

用户在概览中，可以看到实盘账户（总）、各虚拟账户（实盘 + 仿真）的账户信息，计划任务，告警信息（分类显示，分策略和系统）。

## 3. 策略

用户通过该界面浏览当前的策略，运行回测，查看回测报告，将回测转仿真和实盘。

### 3.1. 策略管理

- 用户可以列出系统中所有的用户策略和内建策略；
- 用户策略可能有更新。更新后能通过扫描（手动，界面触发）后，加载到策略显示列表（策略选择器？）
- 用户可以选择屏蔽某个策略（不删除，但不可见）。当他这样做时，该策略对应的所有回测结果也将不可见。
- 用户可以删除自定义的策略，当这样做时，所有关联的回测报告也将删除（不能删除正在进行实盘的策略，仿真可以）

### 3.2. 回测管理

- 用户可以对策略进行回测。在回测前，他可以指定运行时参数和策略参数。
- 回测过程中，实时显示回测状态。在回测结束后，回测报告和日志自动保存
- 用户可以删除某次回测报告，或者全部回测报告。
- 通过选定某个策略，就可以看到该策略所有的回测报告（列表展示），并可以按年化收益、sharpe,sortino 和最大回撤进行排序
- 回测报告是一组报告，包括概览、每日成交、每日持仓、日志
- 概览要显示参数快照（运行时、策略参数，只读）、评估指标、净值曲线、交易信号、回撤图、月度热力图
- 每日成交要显示本次回测所有的成交记录，按时间排序，可导出 CSV
- 每日持仓要显示回测区间内每日的持仓快照，可按日期跳转
- 日志要显示回测运行的 stdout/stderr，可下载到本地
- 在回测报告中，日志可删除

### 3.3. 仿真与实盘

- 用户可以在回测列表上操作，使它投入仿真或者实盘（遵循后台的调度约束），成为一个运行时实例
- 用户可以列出所有正在进行仿真的策略，并查看它们的运行详情（含账户资产、净值曲线、评估指标、订单事件、风控事件、心跳和错误）
- 在查看仿真策略的详情时，可以暂停或终止策略仿真
- 用户可以列出所有正在进行实盘的策略，并查看它们的运行详情（含账户资产、净值曲线、评估指标、订单事件、风控事件、心跳和错误）
- 在查看实盘策略的详情时，可以暂停或者终止策略实盘（这不等于停止实盘账户。一个实盘账户可能同时运行多个策略）
- 可以查看运行时实例的状态（运行中、暂停、终止）
- 暂停中的运行时实例可以再次启动
- 投入实盘的策略，在净值图上，要使用单 Y轴双线图显示真实净值和并行仿真的模拟净值

> Aaron: 暂停（dry-run）是策略继续运行，但订单不会发出。终止是完全退出。之后策略必须以全新的实例再次运行。

### 3.4. 风控触发事件详情

风控策略在 [001 §1.9](../v0.2-001-strategy-framework/story.md) 触发卖出时，UI 需要展示每次触发的细节。

#### 3.4.1. 触发事件列表

每条触发事件展示以下字段：

| 字段     | 来源                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------- |
| 时间戳   | 触发事件数据流                                                                                                |
| 标的     | 同上                                                                                                          |
| 触发价   | 同上                                                                                                          |
| 成本价   | 同上                                                                                                          |
| 原因     | `reason` 字段                                                                                                 |
| 超额收益 | 按 [001 §1.9 Triple Barrier](../v0.2-001-strategy-framework/story.md) 计算的 N 日窗口（默认 N=0，即当日收盘） |

#### 3.4.2. 触发原因分布

- 饼图或柱状图：按 `reason` 字段分组
- 联动：点击某原因 → 过滤 §3.4.1 触发事件列表

### 4.3. 账户管理

#### 4.3.1. 四种账户

系统区分四种账户：策略仿真账户（仅用于仿真的虚拟账户）、实盘总账户（通过网关连到券商的真实账户）、策略实盘账户（虚拟户，与策略运行时绑定）、风控账户（只能做风控，不能手动交易）。

#### 4.3.2. 策略仿真账户的创建与删除

- 用户在将策略投入仿真时，将创建（自动）新的仿真账户。用户可以指定名字、确定本金。
- 仿真账户不可删除，但可以隐藏 -- 不在 UI 上显示，也可以重新在 UI 上显示。隐藏状态需要记录在数据库中。
- 隐藏账户前要求账户处于空闲、且没有未结算的持仓；
- 仿真账号没有重置账户。
- 被隐藏的账户不参与各类合计统计

#### 4.3.3. 实盘总账号的接入

用户想接入一个实盘账户时，先要选一个已经配置好的网关，系统会立即检查这个网关是不是真的连得通、API Key 是不是有效、延迟在不在合理范围——只有通过了才能往下走。

实盘账户有三个状态：在线、离线、故障。离线时页面会显示告警横幅；网关恢复后账户自动回到在线状态，用户不需要做任何操作。

- 实盘总账号需要从网关处同步资金账户信息、持仓、委托
- 实盘总账号允许修改本金
- 策略实盘账号的资金之和允许不等于实盘总账号，系统不做此类校验

#### 4.3.4 策略实盘账户的创建与删除

- 用户在将策略投入实盘时，将创建（自动）虚拟账户，从实盘总账户中分配资金。
- 在创建时，用户可以指定名字、确定本金。本金一旦指定，后面不可修改。
- 实盘虚拟账户不得删除，但可以隐藏 -- 不在 UI 上显示，也可以重新在 UI 上显示。隐藏状态需要记录在数据库中。
- 隐藏账户前要求账户处于空闲、且没有未结算的持仓；仿真账号没有重置账户。
- 被隐藏的账户不参与各类合计统计

#### 4.3.5 风控账户的创建与删除

- 策略在投入仿真、实盘时，如果指定风控策略，则自动创建。
- 创建时没有任何定制项。名字和 ID 都由系统决定。

## 5. 交易

### 5.1. 实盘交易界面

界面顶部提供**策略选择器**，列出当前所有实盘运行的策略（日线 + 实时），用户可切换查看不同策略的信息。当用户没有选择策略时，显示总账户。但此时不可以进入买入操作。

1. 显示所选策略的账户基本信息
2. 显示所选策略的当日委托、成交并实时刷新
3. 提供基础交易界面，允许用户在紧急情况下手动交易
4. 手动交易必须归属一个目标策略（虚拟账户）；**风控策略不可作为手动交易目标**
5. 界面自动反映订单的委托状态变化。
6. 在当日委托中，可以进行撤单。

#### 5.1.1. 下单辅助

用户在下单表单里下单时，系统会提供一些辅助信息帮助决策：

- 参考价：昨收、5 日均线、10 日均线、实时价可切换、以及在昨收基础上，提供多档涨跌速算价。
- 卖出时自动算"可卖数量"= 持仓 − 已挂单，并明确提示 T+1 约束
- 在持仓列表里双击即可卖出，并自动把标的、数量、价格带到下单表单
- 按金额反算股数（按 100 股取整）

#### 5.1.2. 提交反馈

用户点"提交"后，会立刻看到反馈：

- 成功：toast 提示"已发送，订单号 xxx"，订单出现在当日委托列表顶部
- 失败：toast 红色提示 + 失败原因；表单保持原样不动，方便用户改完再提
- 网关离线：toast 提示"网关离线，订单已暂存"，订单先进入本地队列等网关恢复后自动发送

### 5.2. 仿真交易界面

界面顶部提供**策略选择器**，列出当前所有仿真运行的策略，用户可切换查看不同策略的信息。

同实盘交易界面，但不提供下单辅助。

### 5.3. 委托和成交记录

- 支持列出三态（回测、paper、live）下的委托记录，按策略、个股、时间段进行查询
- 支持列出三态下的成交记录，按策略、个股、时间段进行查询

## 6. 系统管理

### 6.1. 任务调度

- 用户可以看到所有数据同步任务（日线行情、证券列表、交易日历等）的列表
- 任务列表详情可以告诉用户任务多久跑一次，运行结果是什么，有没有出错。
- 用户可以：
  - 启用或禁用某个任务
  - 立即手动跑一次
  - 修改 cron 表达式
- 看每个任务最近 N 次执行的历史——成功还是失败、跑了多久、错误是什么。

### 6.2. 网关管理

- 用户可以重新配置交易网关，包括服务器、端口、url_prefix 和 api KEY
- 用户可以看到网关的连接状态。
- 如果某个网关从健康变成异常，告警中心会立刻出现一条新告警。

### 6.3. 数据完整性校验

## 8. 系统配置（init-wizard）

用户在安装后第一次打开系统时，会被强制带入 init-wizard。Wizard 一步一步引导用户完成系统启动所必需的配置：欢迎页 → 运行环境（监听地址、端口、URL 前缀、是否仅本机访问）→ 管理员账号（用户名 + 密码）→ 数据目录 → 数据源（一个或多个网关）→ 首次下载范围（交易日历起止、股票列表快照）→ 下载进度（实时显示每个任务的进度，可以选择跳过失败的）→ 通知渠道（可后置）→ 完成页。

Wizard 的入口对未初始化系统强制开放；对已初始化系统作为"重新配置"模式（§8.3），从系统设置进入。

### 8.1. 首次安装

（详见上面 §8 的主流程）

### 8.2. 失败恢复

如果 wizard 任何一步失败（数据下载失败、网关连不上等），用户会停留在那一步，看到错误详情和"重试"按钮。用户可以重试，也可以选择"跳过该步骤"把它标记为待处理。已经成功的步骤不会被回退；用户重新进入 wizard 时会从失败的那步继续。

主界面顶部会用横幅提醒用户还有"待处理"的 wizard 步骤。

### 8.3. 重新配置

已经初始化完成的系统，管理员可以从"系统设置"里再次进入 wizard 做"重新配置"。和首次安装的区别是：不允许通过 wizard 改管理员密码、不允许通过 wizard 改数据目录。其它项（运行环境、网关、通知、首次下载）都可以再调一次。完成后回到主界面，不重启进程。

### 8.4. 未配置交易网关

允许用户在未配置交易网关的情况下运行系统。此时仿真和实盘功能都不可用。用户只能时行回测研究。
