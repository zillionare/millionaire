# Millionaire UI — Story

本文件汇总所有面向用户、需要在 Web 界面中呈现或由用户操作触发的故事。**计算规则、调度规则、数据契约、撮合规则等业务规则不在本文件范围内**，仍由 [v0.2-001-strategy-framework](../v0.2-001-strategy-framework/story.md) 承载；本文件通过引用 001 的对应章节联动上游。

> **来源说明**：本文件的多数章节最初散落在 `v0.2-001-strategy-framework/story.md` 中，由 2026-06-17 的迁移整理集中到本文件。具体迁移记录见文件末尾"§19. 迁移记录"。

## 1. 策略发现与展示

### 1.1. 策略选择器

界面左侧面板提供**策略列表**，列出当前所有可用的策略。消费 [001 §1.2 自动发现](../v0.2-001-strategy-framework/story.md) 产出的策略元数据列表，但只显示策略名称和版本号。当点击列表中的某一个 item 时，自动在右侧显示该策略的基本信息（上方）以及基于该策略的所有回测列表（下方，显示回测运行时间、起止时间、年化收益等）。

策略的基本信息包括：

| 字段              | UI 展示  | 说明                             |
| ----------------- | -------- | -------------------------------- |
| `name`            | 主标题   | —                                |
| `description`     | 副标题   | docstring 首行                   |
| `strategy_type`   | 类型徽章 | `day` / `live` / `risk`          |
| `is_builtin`      | 来源标签 | "内置" / "用户"                  |
| `default_config`  | 参数摘要 | key=value 列表；空时显示"无参数" |
| `skipped_reasons` | 警告徽章 | 仅未识别类显示；悬浮显示详细原因 |

### 1.2. 内置 vs 用户策略的优先级

| 场景                               | 规则                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------- |
| `strategy_id` 不冲突               | 内置与用户策略**都展示**，可分别选择运行                                     |
| `strategy_id` 冲突（用户策略同名） | 列表中**用户版本优先**；内置版本隐藏，但可通过"显示被覆盖的内置策略"开关看到 |
| 排序                               | 默认按 `is_builtin=False` 优先，然后按 `name` 字母升序                       |
| 过滤                               | 支持按 `strategy_type` 多选过滤、按 `is_builtin` 切换                        |
| 搜索                               | 按 `name` / `description` / `strategy_id` 模糊匹配                           |

## 2. 运行时参数编辑

用户启动回测/仿真/实盘前，编辑运行时参数；运行时参数**不被回测结果锁定**（[001 §1.13](../v0.2-001-strategy-framework/story.md)）。运行时参数定义（本金/滑点/印花税比率/佣金比率/单笔最低佣金）见 001。

| 字段               | UI 控件    | 默认值   | 校验           |
| ------------------ | ---------- | -------- | -------------- |
| 本金               | 数字输入   | 上一次值 | `> 0`          |
| 滑点（比率）       | 百分比输入 | `0`      | `0 ≤ x ≤ 0.1`  |
| 印花税比率（卖方） | 百分比输入 | `0.001`  | `0 ≤ x ≤ 0.01` |
| 佣金比率           | 百分比输入 | `0.0003` | `0 ≤ x ≤ 0.01` |
| 单笔最低佣金       | 数字输入   | `5`      | `≥ 0`          |

用户最近一次值缓存在本地，**不写入回测结果**。切换运行模式时，UI 提供"沿用上次 / 重新设置"两选项，默认沿用上次。

## 3. 调度操作界面

调度路径与生命周期规则在 [001 §2 策略调度](../v0.2-001-strategy-framework/story.md) 中定义；本节仅定义 UI 操作。

### 3.1. 启动回测

- 入口：策略列表 → 选中策略 → "启动回测"
- 表单：策略参数（来自 `default_config`，可编辑）+ 运行时参数 + 回测区间（起止日期）
- 提交后：进入回测进度视图（§5）

### 3.2. 转入仿真 / 实盘

- 入口：已完成的回测结果 → "转仿真" / "转实盘"
- 仅日线策略有此入口；日内策略走 [001 §2.2](../v0.2-001-strategy-framework/story.md) 路径（无回测，直接进入仿真或实盘）
- 表单：运行时参数（允许覆盖）+ 运行时模式

### 3.3. dry-run 切换

详见 §4。

### 3.4. 停止

- 入口：任意运行中策略 → "停止"
- 立即生效；**已发订单不撤回**

## 4. dry-run 切换与并行仿真视图

[001 §8 dry-run](../v0.2-001-strategy-framework/story.md) 行为定义在本节呈现为 UI。

### 4.1. 切换

- 进入：策略菜单 → "进入 dry-run" → 二次确认（标注"已发订单仍会成交"）
- 退出：策略菜单 → "退出 dry-run"
- 状态显示：策略行有 `dry-run` / `live` / `paper` 徽章

### 4.2. 并行仿真视图

- 触发：进入实盘时，框架自动创建并行仿真（[001 §2.1/2.2](../v0.2-001-strategy-framework/story.md)）
- UI 在该策略详情页提供**双 Y 轴净值曲线**：
  - 主轴：实盘 / dry-run 期间的真实净值
  - 副轴：并行仿真的模拟净值
- dry-run 期间的指标"参考并行仿真"（[001 §8](../v0.2-001-strategy-framework/story.md) 原文）

## 5. 回测进度可视化

实现 [001 §4.5](../v0.2-001-strategy-framework/story.md) 的 UI 表现：回测进行时 UI 实时更新。

### 5.1. 进度条

- x 轴：回测区间
- 当前推进点：高亮标记
- 百分比：已处理交易日 / 总交易日

### 5.2. 净值曲线

- 主轴：策略净值
- 副轴：参照标的（默认沪深 300，可配）
- 数据点：随 `on_bar` 推进逐点增加

### 5.3. 实时指标

- 显示"可在回测中计算的指标"：当前持仓、当日盈亏、累计交易笔数
- **不在回测中显示**的指标（需结束时计算）：年化、最大回撤、Sharpe、Sortino、Calma
- 显示占位符："回测结束后计算"

### 5.4. 交易标注

- 买入点：K 线图上叠加 ▲ 标记
- 卖出点：K 线图上叠加 ▼ 标记
- 鼠标 hover：显示价格、数量、时间

## 7. 风控触发事件详情

风控策略在 [001 §1.9](../v0.2-001-strategy-framework/story.md) 触发卖出时，UI 除展示 §6 中的超额收益曲线外，还需展示每次触发的细节。

### 7.1. 触发事件列表

每条触发事件展示以下字段：

| 字段     | 来源                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------- |
| 时间戳   | 触发事件数据流                                                                                                |
| 标的     | 同上                                                                                                          |
| 触发价   | 同上                                                                                                          |
| 成本价   | 同上                                                                                                          |
| 原因     | `reason` 字段                                                                                                 |
| 超额收益 | 按 [001 §1.9 Triple Barrier](../v0.2-001-strategy-framework/story.md) 计算的 N 日窗口（默认 N=0，即当日收盘） |

### 7.2. 触发原因分布

- 饼图或柱状图：按 `reason` 字段分组
- 联动：点击某原因 → 过滤 §7.1 触发事件列表

## 8. 账户总览

- 汇总展示所有运行中策略的账户基本信息（总资产、可用现金、持仓市值、账户盈亏）
- 支持按策略筛选，查看单策略账户详情

## 9. 委托和成交记录

- 支持列出三态（回测、paper、live）下的委托记录，按策略、个股、时间段进行查询
- 支持列出三态下的成交记录，按策略、个股、时间段进行查询

## 10. paper / live 账户

- 每日收益率查询及净值曲线（可视化）
- 月度收益热力图
- 支持查询最大 N 亏损、最大 M 盈利个股
- paper / live 的账户基本信息（总资产、可用现金、持仓市值、账户盈亏）

## 11. 实盘交易界面

界面顶部提供**策略选择器**，列出当前所有实盘运行的策略（日线 + 实时），用户可切换查看不同策略的信息。

1. 显示所选策略的账户基本信息
2. 显示所选策略的当日委托、成交并实时刷新
3. 提供基础交易界面，允许用户在紧急情况下手动交易
4. 手动交易必须归属一个目标策略（虚拟账户）；**风控策略不可作为手动交易目标**

## 12. 仿真交易界面

界面顶部提供**策略选择器**，列出当前所有仿真运行的策略，用户可切换查看不同策略的信息。

1. 显示所选策略的账户基本信息
2. 显示所选策略的当日委托、成交并实时刷新
3. 提供交易界面，供用户**补单**（防止自动化失败的补救措施）

## 16. 通知配置界面

事件触发列表（委托 / 成交 / 失败 / 网关断开）定义在 [001 §9 消息通知](../v0.2-001-strategy-framework/story.md)。本节仅定义配置 UI。

微信通知通过**二维码扫描启用**：

1. 系统设置 → 通知 → 微信 → "启用"
2. UI 生成一次性二维码（含临时 token）
3. 用户扫码关注公众号并发送 token
4. 后台确认绑定后，UI 显示"已启用"

配置项：

- 启用 / 停用微信通知
- 事件订阅：可独立勾选"委托"、"成交"、"失败"、"网关断开"
- 静默时段：可选 22:00–08:00 不推送

## 17. 系统配置（init-wizard）

系统在安装后的首次启动时，运行 **init-wizard**（通过 web）来引导用户配置关键项：

- 登录密码
- qmt-gateway 连接
- 通知渠道配置（联动 §16）
- 数据源
- 数据目录

## 18. 非功能需求

### 18.1. 响应性

- 页面首屏渲染 < 2s（本地网络）
- 委托 / 成交列表实时刷新延迟 < 5s
- 大数据量（>10k 委托记录）下表格滚动不卡顿（虚拟滚动）

### 18.2. 可访问性

- 关键交互支持键盘导航
- 颜色对比度符合 WCAG AA

### 18.3. 错误降级

- 数据源不可用时，UI 显示"数据加载失败，正在重试"，而非空白页
- qmt-gateway 断开时，实盘策略详情页顶部显示红色横幅告警
