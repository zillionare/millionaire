## 二、本轮发现的新问题

### P1 — 应修复 (3 项)

#### 1. spec §2.8 init-wizard 步骤顺序与 AC-2 不一致

spec §2.8 UI-FR-0460 首次安装流程:

```
1. 欢迎 → 2. 运行环境 → 3. 管理员账号 → 4. 数据目录
→ 5. Tushare → 6. 网关(可选) → 7. 首次下载 → 8. 下载进度
→ 9. 通知(可选) → 10. 完成
```

AC-2 (Aaron Round 5 Q3, Round 6 应用):

```
1. 欢迎 → 2. 登录密码 → 3. 运行环境 → 4. 通知(可选)
→ 5. Tushare → 6. 网关(可选) → 7. 数据目录 / 首次下载 / 下载进度 / 完成页
```

两处差异:
- 登录密码: spec 排第 3, AC 排第 2
- 通知配置: spec 排第 9 (下载后), AC 排第 4 (运行环境后)

建议以 spec 为准 (因为 spec 是需求文档, AC 是验证条件), 统一 AC-2 与 spec 一致。或者由 Aaron 确认正确顺序后回写 spec。

#### 2. spec §2.8 失败恢复规则与 AC-3 矛盾

spec 失败恢复仍写:
> "对必选项，任何一步失败时, 用户停留在该步骤, 看到错误详情和'重试'按钮"

但紧接着:
> "对可选项，用户可以配置、可以跳过，也可以在配置错误后选择跳过"

这里逻辑清晰: 必选项只能重试, 可选项可以跳过。spec 本身已经修正了。

但 spec 的 UI-US-0820 (用户故事层) 仍写:
> "wizard 任何步骤失败时，我能重试或跳过该步骤"

"任何步骤" 包含了必选项也能跳过 — 与 spec §2.8 正文矛盾。应更新 US-0820 措辞为 "必选步骤失败时重试，可选步骤失败时可跳过"。

#### 3. spec §2.5 参考价"十日"与 story §5.1.1 "5日均线"不一致

spec §2.5 UI-FR-0420 参考价 3×4 布局:
> 昨收、实时、五日、**十日** ｜ 跌停、-3%、-2%、-1% ｜ 1%、2%、3%、涨停

story §5.1.1 下单辅助:
> 参考价：昨收、**5 日均线**、实时价可切换

story 只提到 "5 日均线"，没有 "10 日均线"。spec 增加了十日，但 story 未同步。AC-3 也列出了 "十日"，AC-14 也验证五日/十日。

建议: 如果 "十日" 是有意新增的，回写 story §5.1.1 加上 "10 日均线"；如果是误加，从 spec 中删除。
