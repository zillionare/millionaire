## 1. 为什么做

Millionaire 社区版（CE）在 v0.5 交付前已具备数据底座、三模式一致的 Broker 抽象、因子检验、LightGBM 训练选股、参数优化、SHAP 单笔决策归因、离线审计内核与日线 Shadow-Run。本规格把当时影响传播力与留存的两类关键断层的修复固化为可验收合同：

1. **核心杠杆的最后一公里与小白网页闭环**：系统已有 LightGBM 策略骨架，理论上“每增加一个有效因子，就能通过不同因子组合裂变出多套策略”。交付前因子入口、因子目录/策略目录/AI 模型配置引导和 Web AI 工坊仍需补齐。用户需要能**直接通过 Web 界面与内置 AI Agent 自然语言对话**，在网页内一站式完成“提出想法 → AI 生成因子代码 → 自动过风洞拦截并修复未来函数 → 查看 IC 与共线性 → 一键组合成多套 LightGBM 预设策略对比回测”，同时为进阶开发者保留 CLI 与外部 Agent Skill 接口。
2. **新用户前 5 分钟体验门槛高、硬核能力外显不足**：首次安装必须先准备带权限的 Tushare Token 并等待下载才能看到 ML 回测与 SHAP 归因；代码里已经实现的未来扰动风洞审计藏在源码 CLI 中，Web 界面看不见；`README.md` 仍偏纯文字说明书；同时路线图中的 30 分钟 Shadow-Run、免积分日线兜底、历史时点（PIT）股票池排雷等实战拼图尚待收口。

本版本聚焦把 Millionaire CE 打磨为 **“面向小白与 AI 的 A 股量化风洞工作台”**：用户在浏览器里用自然语言提想法、AI 负责写因子，Millionaire 负责严防未来函数、检查因子正交性、通过 LightGBM 组合裂变策略、用 SHAP 解释单笔决策、用 Shadow-Run 监控持续运行走样，并让新用户在 3 分钟内免 Token 跑通全流程。

## 2. 版本与产品边界裁定（锁定决策）

为保持社区版（CE）与专业版（**millionaire pro**）边界清晰、兼顾小白易用性与开发者可扩展性，以下切分已由维护者确认并作为本规格约束：

### 2.1 纳入本规格（Millionaire CE 实施范围）

1. **初始化全目录引导与 Web 内置 AI 因子工坊**：初始化向导统一预填并配置数据目录、因子目录、策略目录（均提供服务可写的持久默认路径，小白免手敲），并提供可跳过的 AI 模型配置步（OpenAI 兼容接口）；Web 端内置轻量 Tool-Calling Agent 会话界面，让不会编程的用户仅靠网页聊天即可完成因子开发、风洞自动修复、IC/正交性检验与策略预设回测；同时保留结构化 `--json` CLI 与官方 `SKILL.md` 供外部编程 Agent 集成。
2. **因子插件底座与策略裂变闭环**：外部因子插件目录与声明式契约、单因子一键风洞校验、与现有因子库的截面正交性/相关性检查、因子组合预设（Factor Preset）与一键消融对比（Ablation）。
3. **开箱即用与传播亮点**：内置/一键加载免 Token 离线体验数据包、Web 端「风洞体检卡片/徽章」可视化、`README.md` 首屏叙事对齐与竞品定位对照。
4. **CE 投研完备性与路线图收口**：免积分历史日线数据源兜底（与 `v0.4-002` 对齐）、历史时点（PIT）股票池排雷规则、LightGBM 截面超额收益与截面秩训练标签、1 个教学级可启用开源风控扩展示例、30 分钟策略 Shadow-Run 逐 bar 对照生命周期、跨平台审计门禁补齐与原生未签名安装包首屏系统放行指引。

### 2.2 归属 millionaire pro 的内置能力（CE 官方不预置，但开放扩展允许用户/AI 自行补齐）

以下能力在 **millionaire pro** 中作为官方开箱即用的内置模块提供；**CE 官方发行版不预置交付这些现成实现，但框架扩展边界保持完全开放，允许且支持用户自己（或借助 AI）在外部目录与扩展接口中自行开发补齐，框架绝不做人为封堵或字段拦截**：

- **扩展横截面基础与基本面衍生字段**：**millionaire pro** 内置换手率（`turnover_rate` / `turnover_rate_f`）、估值指标（`pe_ttm`、`pb`）、量比等扩展字段的标准采集与落库；CE 官方 `daily_basic` 仅预置 `total_mv` 与 `circ_mv`，但允许用户在自定义数据源/自定义面板中附加任意扩展列并供外部因子插件和自定义策略读取。
- **正式行业分类与行业/市值中性化**：**millionaire pro** 内置申万等正式行业分类体系及一键行业/市值中性化管线；CE 官方不内置行业库与中性化开关，但允许用户在自定义因子插件或外部研究面板中自行引入行业映射并编写截面回归/去均值逻辑。
- **机器学习调仓换手抑制与持仓缓冲带**：**millionaire pro** 内置 `hold_buffer` / `buffer_k` 排名缓冲带、最小调仓阈值等实盘降换手组件；CE 官方内置 ML 示例保持简洁清晰的 `top_k` 截面调仓参考逻辑，但允许用户/AI 在用户策略目录（`strategy_dir`）中继承或编写自己的缓冲带调仓策略。
- **成熟风控包与实盘柜台接入**：真实交易开关/UI、内置三重障碍止盈止损、移动回撤卖出、成本止损归属 **millionaire pro**；CE 保留开放的 `RiskProgramAdapter` 用户风控扩展接口与 HTTP 柜台协议参考，供用户在合规范围内自行研究扩展（CE 运行时实盘开关 `supports_live_trading()` 边界维持不变）。

### 2.3 明确暂不实施（Out of Scope / 延后）

除 `docs/roadmap.md` 已列出的未完项外，其余运维与外围工程尾项在本版本一律不做：

- **不做**柜台适配 OpenAPI 规范文件生成与第三方网关一键协议验收靶场 CLI（保留现有 `simulated-counter` 与适配文档即可）。
- **不做**钉钉/邮件异常告警与盘后同步失败、行情断流、Shadow-Run 净值偏离联动触发及 UI 一键测试。
- **不做**商业 Apple Developer ID 公证与 Windows 代码签名证书接入（本版本仅在安装文档首屏补齐 SHA256 校验与系统放行步骤）。

## 3. 用户目标

1. **不会编程的小白用户 / 首次体验者**：安装完成后，向导已自动填好安全可用的数据目录、因子目录与策略目录，无需填任何数据源 Token 即可 3 分钟用内置体验包跑通全链路；填上自己的大模型 API Key（如 DeepSeek / 通义千问 / OpenAI）后，**全程只需在浏览器里跟 AI 聊天**，不用碰命令行或代码编辑器，就能把一个中文选股想法变成经过风洞检验的新因子和可回测的策略预设。
2. **进阶开发者 / 外部 AI Agent 用户**：可通过 `millionaire` 结构化 `--json` CLI 和官方 `SKILL.md`，在 Claude Code / Copilot / Cursor 中批量驱动因子生成、风洞校验、IC 研究与预设回测，或自行在策略目录与扩展接口中编写高阶逻辑。
3. **组合策略研究者**：每次新增一个通过风洞且低共线性的因子后，能把不同的「因子子集 + 训练标签/窗口参数」保存为多个具名策略预设（Preset），并一键运行消融回测（Ablation），看清这个新因子究竟给组合带来了多少增量收益或回撤改善。
4. **无高积分 Tushare 账号的个人量化用户**：能用免积分历史日线数据源完成日常回测与因子研究，并按历史当日真实状态（PIT）剔除 ST/\*ST、退市整理、刚上市新股、停牌与一字涨跌停股票，避免回测踩中常见幸存者偏差与流动性假象。
5. **从日线走向分钟级验证的用户**：运行 30 分钟策略仿真时，系统像日线一样提供逐闭合 30m bar 的 Shadow-Run 回测对照，区分盘中执行偏差与策略自身失效；也能通过 1 个开源教学风控示例理解如何挂载自己的风控规则。

## 4. 核心用户旅程

### 4.1 全目录向导初始化与免 Token 3 分钟开箱体验旅程

1. 用户下载安装原生包并打开 `http://127.0.0.1:8130` 进入初始化向导。
2. 在“运行环境”步骤，页面清晰展示 **数据存储目录**、**用户因子目录**、**用户策略目录** 三项配置，且均已预填好对后台服务账户可写的持久化默认目录（升级不丢失）。小白用户无需手敲路径，直接点“下一步”即可完成目录建档与权限核验；进阶用户也可改为自定义外部目录。
3. 设置管理员密码后，在“数据源”步骤，用户除了填写 Tushare Token 或选择免积分历史源外，看到醒目的 **“先用内置体验数据包快速体验（免 Token、离线可用）”** 选项并直接选用。
4. 向导进入**可选（可一键跳过）的“AI 助手配置”步骤**：用户可顺手选择服务商模板（如 DeepSeek、通义千问、OpenAI、本地 Ollama）、粘贴 API Key 并点“测试连接”，也可直接点击“跳过，稍后配置”。
5. 进入主界面后，体验数据包已挂载在隔离演示空间（顶部横幅提示“当前为体验数据集”并提供切换正式数据源入口）。用户点开“因子”看到预置因子的 RankIC、十分位收益柱状图与绿色 **“风洞体检：已验证”** 徽章；点开“策略”运行 `MLMomentumReversalStrategy`，在 K 线买卖点直接看到 SHAP 因子贡献瀑布与账户收益归因。

### 4.2 小白在 Web 界面与 AI 会话开发并检验因子（主路径）与外部 Agent CLI（进阶路径）

#### 主路径：Web「AI 因子工坊」零代码会话闭环

1. 不会编程的用户点击顶部“因子”进入 **「AI 写因子（AI 因子工坊）」** 对话面板（若初始化时跳过了 AI 配置，面板内直接弹出简明 API Key 配置引导）。
2. 用户用自然语言输入：“帮我写一个捕捉近 10 天缩量回调后、今天放量阳线反包的日线因子，检查有没有未来函数，看看预测效果和现有因子重不重复。”
3. 内置 Agent 在网页对话流中以可视化步骤卡片推进全流程（无需用户离开浏览器）：
   - **明确口径与生成代码**：向用户简明解释拟定的计算逻辑，自动将规范插件文件写入已配置的“用户因子目录”（可展开查看代码，默认对小白折叠技术细节）；
   - **自动送入风洞与自我修复**：后台子进程立即执行确定性风洞校验。若首版代码误写了跨股票 `shift` 或未来引用导致风洞返回 `FAIL`，对话流透明显示“第 1 次风洞拦截：检测到跨股票边界串算 → AI 正在自动修正代码 → 第 2 次风洞体检：全部通过 `PASS`”（自动修复最多重试 3 轮，超出则停下并诚实告知原因，绝不偷改风洞标准或无限消耗额度）；
   - **输出通俗检验与查重卡片**：风洞通过后自动计算快速检验摘要，在对话内直接渲染通俗结论卡片——主持有期 RankIC、十分位多空收益柱状图，以及与现有因子库的最大截面相关系数（例如：“与现有 `rev_5d_shrink_vol` 相关度 `0.41`，具备独立增量信息”）。
4. 对话卡片底部直接提供操作按钮：**“纳入自动跟踪”** 与 **“与现有因子组合回测对比”**。用户点击后者，即可一键生成包含该新因子的 LightGBM 策略预设并跳转查看消融对比报告。

#### 进阶路径：外部编程 Agent 通过 CLI + Skill 批量挖掘

1. 习惯使用 Claude Code / Copilot / Cursor 的开发者启用仓库随附的官方 `SKILL.md`。
2. 外部 Agent 通过与 Web 工坊同源的 `millionaire factor init / check / study` 与 `millionaire preset save / backtest run --json` 命令无界面驱动同一套风洞、查重与消融回测流水线，产出完全一致的指纹证据，并在 Web 界面同步可见。

### 4.3 因子组合裂变与消融对比旅程

1. 用户在 LightGBM 策略配置界面勾选不同的因子组合与训练标签（如“绝对收益标签” vs “截面秩标签”），将其分别保存为具名预设，例如 `基础量价_25因子`、`量价+缩量反包_秩标签`、`纯反转精简_8因子`。
2. 用户选择基准预设 `基础量价_25因子` 与候选预设 `量价+缩量反包_秩标签` 发起 **消融对比（Ablation）**。
3. 系统固定相同的回测区间、PIT 股票池规则、手续费与随机种子运行对照，并排展示两者的净值曲线、年化超额、最大回撤、换手率以及新增因子在 SHAP 中的平均贡献排名，让“多一个因子 = 多几套可验证策略”形成直观闭环。

### 4.4 Web 风洞体检徽章查看旅程

1. 用户打开任意已登记因子的详情页或策略回测报告页，顶部展示一枚 **风洞体检状态徽章**（`已通过 PASS` / `未通过 FAIL` / `证据不足 INCONCLUSIVE` / `代码或数据已变更 STALE` / `未运行 UNVERIFIED`）。
2. 展开“风洞体检卡片”可查看人类可读的四项证据摘要：未来数据截断扰动检验、跨证券边界隔离检验、随机置换对照、账户守恒不变量（回测报告页），以及绑定的源码/配置/数据指纹。
3. 一旦用户或 AI 修改了该因子 `.py` 文件，旧的 `PASS` 徽章立即变为 `STALE（需重检）`，防止改坏代码后继续顶着旧通过徽章误导决策。

### 4.5 免积分历史日线、PIT 选池与教学风控旅程

1. 没有 Tushare 积分的用户在初始化向导或数据源管理中选择免积分历史日线源（如 BaoStock 日线），即可同步历史日线、复权因子与基础交易状态开展日线与月线研究。
2. 在因子研究与日线 ML 回测中，用户可开启并查看透明的 **PIT 股票池过滤规则**（剔除当日 ST/\*ST、退市整理期、上市未满 N 个交易日新股、当日停牌、一字涨跌停不可成交股），报告明确记录每个过滤条件排除了多少样本，杜绝用“今天是否 ST/退市”去过滤三年前样本的未来泄露。
3. 想了解“主策略与风控叠加”的用户，按文档一键启用 CE 附带的教学参考风控扩展（如单笔/单标的仓位上限示例），在保持 CE 默认注册表为空契约的前提下，亲手跑通回测叠加层与仿真 `RiskStrategy` 联动，再让 AI 仿照该模板编写自己的风控。

### 4.6 30 分钟策略 Shadow-Run 与桌面安装放行旅程

1. 用户将 `BAR_INTERVAL = "30m"` 的策略转入仿真后，系统按每个已闭合的 30 分钟 bar（10:00、10:30、11:00、11:30、13:30、14:00、14:30、15:00）在对应历史分钟 bar 就绪后自动推进影子回测账户，并在 `/tracking/<仿真账户ID>` 页面展示逐 bar 对照曲线、持仓差异与缺口状态；服务中途重启后从最近已闭合 bar 幂等恢复，不重发委托、不漏算已闭合窗口。
2. macOS 与 Windows 新用户在阅读安装文档第一屏时，即可看到清晰的 SHA256 校验方法与未签名安装包系统放行步骤（macOS Gatekeeper / Windows SmartScreen），不会因系统首次拦截误判安装包损坏。

## 5. 用户可感知的成功结果

- 初始化向导自动就绪数据、因子、策略三个持久化目录；不填任何数据源 Token，安装后 3 分钟内即可在本地浏览器跑完一次含 SHAP 决策解释的 LightGBM 回测与因子检验。
- 不会编程的小白用户只需配置一个常见大模型 API Key，即可全程在 Web「AI 因子工坊」对话中完成新因子编写、风洞自动排错修复、IC/查重检验与策略预设回测；进阶用户也可通过 CLI + `SKILL.md` 用外部 Agent 驱动同一套后端能力。
- 每新增一个有效因子，用户都能保存多套具名因子组合预设并一键查看消融增量对比。
- 因子页与回测报告页直接可见指纹绑定的风洞体检卡片，`README.md` 首屏一眼传达核心差异化价值。
- 无积分用户可顺畅拉取免积分日线并启用严格的 PIT 排雷选池；30 分钟策略拥有与日线一致的 Shadow-Run 双实例对照能力；有进阶需求的用户还可在开放扩展目录中自行（或让 AI）补充自定义字段、策略与风控逻辑。

## 6. 2026-11-18 补充用户可见边界

- 用户在 AI 工坊连续发起两轮需求时，最终页面只呈现最新一轮的结论和卡片；上一轮稍后返回的模型或 IC 结果不会覆盖已完成的新轮次。
- 研究、消融与 SHAP 解释可以使用独立不可变模型引用回放，但不会改变正在运行的 Paper 账户下一次决策所加载的正式模型。
- 30 分钟影子任务在同一闭合 bar 的后续 tick 仍会处理待执行 `next_open` 意图；策略信号本身不会重复触发。重启后不会把当前账户状态补写成过去槽位的历史事实。
