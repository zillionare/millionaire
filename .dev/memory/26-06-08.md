## 决策

1. **fallback 模型链调整**：所有 agent 和 category 的 `fallback_models` 链末尾从 `opencode-go/glm-5.1`（opencode-go 提供商、未订阅）改为 `astroncodingplan/xopglm51`（用户订阅的讯飞星辰 coding plan）。sisyphus 主模型 MiniMax-M3 → kimi-2.6 → glm-5.1。
2. **#30 实施方案**：参考 `.dev/specs/09-backtest-report-tabs-and-logs.md` 的服务端 query 参数驱动模式（不是前端 show/hide）。tab 容器用顶部 inline `<a>` 链接（trade page 没有侧边栏子菜单），保持刷新可恢复、直接分享链接稳定。
3. **测试隔离修复**：`tests/web/test_trade.py` 存在预先就有的 `test_app` module-scope fixture 隔离问题——`TestSimulationBroker` 跑过之后，后续用到 `test_client` 的测试会因 SQLite 单例状态被破坏而失败。新增的 `TestPositionsOrdersTabs` 必须紧跟 `TestTradeMain` 之后插入，不能放到文件末尾。
