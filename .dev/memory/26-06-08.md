# 2026-06-08 对话记录

## 用户请求

1. 修改 `oh-my-openagent.json`，让所有 agent/category 的 fallback 链以 `astroncodingplan/xopglm51`（讯飞星辰 glm-5.1）作为最终兜底，避免 usage limit exceeded 时工作中断。
2. 完成后继续 #30（持仓/委托 tab 化），需求来源：<https://github.com/zillionare/millionaire/issues/30>。
3. 修复 #37（toast 关闭按钮无效）、#38（双击闪电单不创建委托）、#39（更新闪电单文案）、#40（闪电单价格选项调整）。每个 issue 修完独立 commit，**不**等 4 个修完一次提交。

## 决策

1. **fallback 模型链调整**：所有 agent 和 category 的 `fallback_models` 链末尾从 `opencode-go/glm-5.1` 改为 `astroncodingplan/xopglm51`。
2. **#30 实施方案**：服务端 query 参数驱动（`?tab=positions` / `?tab=orders`），tab 用顶部 inline `<a>` 链接（trade 页面无侧边栏子菜单）。
3. **#37 根因**：上层 slot 用了 `pointer-events-none` 防止空 slot 拦点击，但内层 toast 即便有 `pointer-events-auto`，在某些场景下 × 按钮的 click 仍被父级吞掉。修复：把 `pointer-events-auto` 和 `cursor-pointer` 直接钉在 × 按钮自身，不依赖继承。
4. **#38 实现方案**：新增 `/trade/lightning/{portfolio_id}/{asset}/execute` POST 路由，解析 entry.price_ref 到具体价格（current / close / ma5..ma60），调用 `broker.buy_amount(amount_wan*10000, price)`，返回 toast。`_lightning_row` 加 `hx_post` + `hx_trigger="dblclick"` + `hx_target="#trade-toast-slot"`。
5. **#39 文案**：把编辑弹窗顶部文案改为「请设置买入金额和价格以创建闪电单。保存后，在下单界面双击即可立即发出委托，适合提前埋伏多支个股，在接近触发条件时快速下单。」（与 #38 双击执行能力配套使用）
6. **#40 价格选项**：`PRICE_REFERENCE_OPTIONS` 去掉 "close"，新增 `current_p1/p2/p3` 三个 key（对应「现价+1%/2%/3%」）。`_resolve_lightning_price` 对这几个 key 走 `current × (1 + pct)` 路径。
