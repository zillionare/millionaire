## User
`/strategy/` 页面已实现删除回测报告功能，但删除按钮无法触发；控制台同时出现 `Uncaught SyntaxError: redeclaration of const htmlElement`。

## Assistant
定位到两个问题叠加：
1. `strategy_app` 作为挂载子应用时重复注入 `AppTheme.headers()`，导致主题启动脚本重复，浏览器在页面加载阶段报 `const htmlElement` 重复声明。
2. 策略页通过 HTMX 把 `Modal(...)` 注入 `#modal-container` 后，没有统一的 UIkit modal 打开/关闭钩子，导致删除确认对话框显示/关闭链路不稳定，用户无法稳定进入 `POST /strategy/backtest/{portfolio_id}/delete`。

## Changes
- 将 `quantide/web/pages/strategy.py` 中的 `strategy_app` 改为不单独注入 `hdrs`，避免 `/strategy/` 页面重复输出主题启动脚本。
- 新增 `_strategy_modal_script()` 和 `STRATEGY_MODAL_CLOSE_JS`，在策略列表页和回测详情页挂载统一的 modal 打开/关闭逻辑。
- 将策略页内相关 modal 的取消/关闭按钮改为统一调用 `closeStrategyModal()`。
- 为 `tests/web/test_strategy.py` 增加策略页 modal helper 与删除确认弹窗关闭动作的测试。

## Validation
