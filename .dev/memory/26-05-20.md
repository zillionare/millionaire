## 发现的问题
上一次修复（`fix(trade): align quick price buttons with spec`）与 test.html 原型稿仍存在以下差异：

1. **整体布局**：当前用 `grid-cols-12`，原型是 flex（left 固定 280px，middle flex 0.6，right flex 1.2）
2. **搜索框**：当前是 Input + 绝对定位 SVG，原型是 Input + 独立 Button
3. **价格选择行**：原型中 select 和 input 是紧贴的（无 gap），原型用 `rounded-r-none` + `rounded-l-none`
4. **中间面板按钮**：
   - 内容顺序不同：当前用"涨停/跌停"，原型用 `10/-10` 等数字
   - 排列顺序不同：当前是横向排列，原型是 10,5,-1,-6 / 9,4,-2,-7 / ...
   - 样式不同：当前用 colored bg (red-100/green-100)，原型用统一浅灰背景 `#f9fafb`，高度 70px，带阴影
   - 颜色语义：正数用红色 `#b71c1c`，负数用绿色 `#388e3c`
5. **右面板**：当前是"候选票池"（股票名称+价格），原型是 stats-row（昨收/MA5/MA10/MA20/MA30/MA60/现价）+ "闪电单"列表（带编辑/删除按钮）
6. **预估数量标签**：当前是"预估数量"，原型是"预估数量 (股)"
